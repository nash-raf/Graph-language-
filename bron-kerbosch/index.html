    Bron-Kerbosch Maximal-Clique Search

    Bron-Kerbosch is a recursive backtracking algorithm that enumerates every maximal clique in an undirected graph. This example shows how GraphEasy combines functions, sets, graph comprehensions, and recursion to describe the algorithm directly.

    Algorithm State

    Each recursive call maintains three vertex sets:

    Set Meaning
    R Vertices already included in the current clique
    P Candidate vertices that can still extend the clique
    X Previously considered vertices, used to avoid duplicate maximal cliques

    A clique is maximal when both P and X are empty. At that point, no remaining or previously processed vertex can extend R.

    Describing A Neighborhood

    The helper function creates a graph view containing the edges incident to vertex v, obtains its vertices, and removes v itself:

    fn set neighborsOf(graph G, int v) {
    graph H = [G where edge has v];
    set Nv = H.vertices;
    Nv.remove(v);
    return Nv;
}

    The expression edge has v selects edges incident to v. The resulting H.vertices set therefore contains v and all its neighbors.

    Candidate Refinement

    For each candidate vertex v, the algorithm adds it to the current clique and intersects the remaining candidate sets with its neighborhood:

    set R_new = R;
R_new.add(v);

set P_new = P intersect Nv;
set X_new = X intersect Nv;

graph H = [G where vertex in P_new];
bronKerbosch(H, R_new, P_new, X_new);

    P intersect Nv keeps only candidates adjacent to v, so every vertex passed to the recursive call remains connected to every vertex in the growing clique. The graph comprehension gives the recursive call a candidate-focused vertex view while preserving the graph's vertex identifiers.

    After recursion, v moves from P to X:

    P.remove(v);
X.add(v);

    This prevents the same maximal clique from being reported through a different candidate order.

    Complete GraphEasy Program

    fn set neighborsOf(graph G, int v) {
    graph H = [G where edge has v];
    set Nv = H.vertices;
    Nv.remove(v);
    return Nv;
}

fn int bronKerbosch(graph G, set R, set P, set X) {
    if (P.size() == 0 && X.size() == 0) {
        print "maximal clique";
        print R.size();
        return 0;
    }

    set P_work = P;

    while (P_work.size() > 0) {
        int v = P_work.pop();
        set Nv = neighborsOf(G, v);

        set R_new = R;
        R_new.add(v);

        set P_new = P intersect Nv;
        set X_new = X intersect Nv;

        graph H = [G where vertex in P_new];
        bronKerbosch(H, R_new, P_new, X_new);

        P.remove(v);
        X.add(v);
    }

    return 0;
}

graph G {
    nodes: 0, 1, 2, 3;
    edges: 0->1, 1->2, 0->2, 2->3;
};

set R = {};
set P = G.nodes;
set X = {};

bronKerbosch(G, R, P, X);

    Example Result

    The example graph contains the triangle {0, 1, 2} and the maximal edge clique {2, 3}. The program reports their sizes:

    maximal clique
2
maximal clique
3

    The implementation was also tested on a 40-edge graph against an independent Python Bron-Kerbosch implementation. Both produced maximal-clique sizes 4, 4, 5, 8.
