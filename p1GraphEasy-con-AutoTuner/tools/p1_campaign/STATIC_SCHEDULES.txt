Effect-derived static schedules (2026-10-20)

The first supported family is ordered source preparation, independent
destination-owner work, and joined completion. The compiler's normal spatial
analysis supplies the ownership, immutable-domain and alias/effect certificate.
A late pass separately rejects callback context observers, opaque calls,
volatile/atomic operations and unsupported lifecycle behavior. It emits a
constant symbolic plan and a named LLVM proof record. Owner cardinality stays
dynamic. This is schedule lowering; it introduces no new dependency discharge,
floating-point reassociation, frontier deduplication or algorithm replacement.

The runtime checks descriptor version, callback identities, capabilities and
current ownership before executing the same source coverage in native order,
then the existing owner worker team and join. It preserves the preparation
grant and restores the caller's budget. Unmatched invocations retain generic
DAG scheduling. Execution ABI version 4 requires a coordinated rebuild.

Controls:
  SGPL_NO_STATIC_SCHEDULE_LOWERING=1  omit compiler-generated plans
  SGPL_NO_STATIC_SCHEDULE=1           retain generic scheduling, same binary
  SGPL_STATIC_SCHEDULE_STATS=1        compiler activation/refusal diagnostics
  SGPL_STATIC_SCHEDULE_DEBUG=1        diagnostic runtime activation (not timing)

This implementation does not yet lower arbitrary partial DAGs, perform general
transitive reduction, or fuse arbitrary callback chains. Existing ownership,
snapshot and privatization proofs remain authoritative. Unknown obligations
are not removed. The change is independent of full-graph kernel lowering.

The portable campaign runs correctness first, one warmup and 5 fresh-process
primary measurements, then independent 20-pair confirmation, across all 244
cases. It interleaves accepted P1, candidate, identical accepted A/A, same-binary
disabled candidate, and Graptor. PageRank also includes historical float
Graptor alongside double Graptor. Whole-process CLOCK_MONOTONIC is primary;
kernel times are separate. Graptor gettimeofday is sourced from monotonic time.

Reports include every graph/algorithm, raw mean slowdowns and Holm-corrected
one-sided paired permutation tests (100,000 resamples, fixed seed), algorithm
tests, A/A checks, original-50 and duplicate-content sensitivity. A/A failure
invalidates inference for that block and triggers one retained repeat. Repeated
instability stays explicit. No candidate is automatically reverted or promoted.
comparison.html is the complete time table; comparison.json and p1-results.tar.gz
preserve measurements and evidence. Setup failures are separate from performance
regressions. Do not report unmeasured improvements or treat kernel-only gains as
end-to-end gains.
