# Whole-task TDG scheduling proof

`TDGTaskSafety.tla` models a TDG level as a set of whole tasks that starts
together and whose members finish independently. `TDGTaskSafetyProof.tla`
contains machine-checked, parameterized proofs of these invariants:

- No two running tasks have conflicting actual reads and writes.
- A task starts only after every actual predecessor has finished.

The proof quantifies over any finite task and storage-object sets. The TLC
configuration checks every state of a two-task, one-object instance, including
all possible sound read/write summaries and predecessor relations. The unsafe
configuration disables the final pairwise check and must produce a safety
counterexample. Run both checks and the TLAPS proof with
`bash test/pdg_tdg_verification/run_tdg_formal.sh`. Set `TLA_TOOLS_JAR` and `TLAPM` to local official
tool installations, or put them at the script's default build paths.

The proof has an explicit **certificate-soundness assumption**: a task's actual
read and write objects are subsets of its summary, and its actual predecessors
are subsets of the declared TDG predecessors. Storage objects represent
canonical whole allocations. An unresolved alias must be treated as conflicting
with every possible write; an opaque task must never share a level. These are
obligations on the compiler's effect extraction and alias resolution, not
conclusions of TLA+.

The corresponding compiler check is in `pdg.cpp` at final level emission:
every pair must pass `independentWholeTasks`, and no TDG dependency path may
connect them. `test/pdg_tdg_verification/check_tdg_level_certificates.py` independently checks the
emitted debug trace of actual levels, task effects, and edges; a deliberately
mutated trace must fail. The graph/ordinary fixtures compare against serial
output, check actual overlap and the shared level budget, and cover dependent
cases. This checks the mapping between the model and compiler output, but the
debug trace is generated by the compiler and cannot prove that the compiler
captured every real effect.

Here, *completeness* means that no actual conflict or required ordering edge is
missing from a certificate. It does not mean every independent pair is placed
together. The formal result is conditional on complete certificates. Graph
sharing is enabled by default; set `SGPL_TDG_DISABLE_GRAPH_SHARING=1` to force
graph tasks into singleton levels. Effect-extraction coverage and runtime
contracts are not yet proved for the whole language, so the current formal
result does not establish universal soundness of this default. GPU graph tasks
are marked opaque because their process-wide launch and registration state
has no whole-task resource summary.
